# Research sources

Store **substantial, reusable** notes only—not full article dumps.

## Note format

One file per topic or key source cluster. Suggested name: `YYYY-MM-DD-short-slug.md`.

```markdown
# Title

- **URLs:**
- **Accessed:**
- **Context of the source:** (e.g. e-commerce / SaaS / B2B services / government)
- **What it establishes for Asibo:**
- **What it does not establish:**
- **Strength notes:** (single study vs converging evidence)
- **Related decision:** link or title in `../decisions.md`
```

Keep quotes short. Prefer paraphrase + link. If a note is not reusable later, leave it out of this folder.

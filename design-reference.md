# Website Design & Engineering References

## Standards and technical requirements

- **WCAG 2.2:** https://www.w3.org/TR/WCAG22/ — Accessibility requirements for keyboard navigation, contrast, focus, and accessible interactions.
- **Responsive Web Design (MDN):** https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Responsive_Design — Flexible layouts, media queries, responsive images, and mobile adaptation.
- **Core Web Vitals:** https://web.dev/articles/vitals — Measurable loading, responsiveness, and visual stability targets.
- **Google Search Essentials:** https://developers.google.com/search/docs/essentials — Technical search visibility and useful-content guidance.
- **Nielsen Norman Group:** https://www.nngroup.com/articles/ — UX research and guidance on navigation, usability, information hierarchy, and user behavior.

## Design skills

- **Anthropic Frontend Design:** https://github.com/anthropics/skills/tree/main/skills/frontend-design — Guides distinctive visual direction, typography, layout, and polished frontend design.
- **UI/UX Pro Max:** https://github.com/nextlevelbuilder/ui-ux-pro-max-skill — Searchable design styles, color palettes, typography pairings, and UX recommendations.

## Browser testing

- **Playwright MCP:** https://github.com/microsoft/playwright-mcp — Enables agent-driven browser navigation, interaction, inspection, and iterative visual QA.
- **Playwright:** https://github.com/microsoft/playwright — Browser automation and repeatable tests for functionality and responsive behavior.

## Instructions for the agent

Use these references according to their purpose. Distinguish formal standards from design recommendations. Inspect relevant documentation rather than assuming a URL alone provides its contents. Apply the guidance to the actual business, existing codebase, and target audience. Verify the finished website in a browser at mobile, tablet, and desktop sizes. Do not invent business claims, testimonials, or credentials.
